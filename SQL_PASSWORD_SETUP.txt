AIKA SQL PASSWORD SETUP
=======================

This guide explains how to configure the MySQL password used by the WebPage.

1. Open this file:
   Server\Bin\WebPage\WebPage.py

2. Find the get_db() function and update the database connection value:

   password="<YOUR_SQL_PASSWORD>",

3. Save the file and restart the WebPage application.

DATABASE REQUIREMENTS
---------------------

- MySQL must be running.
- The database name must match the database parameter in WebPage.py.
- The configured MySQL user must have permission to read and write the AIKA
  account, character, nation, and related tables.
- If MySQL runs on another computer, update the host value as well.

SECURITY NOTES
--------------

- Do not publish WebPage.py with a real database password in public repositories.
- Use a dedicated MySQL user for the web application instead of the MySQL root user.
- Use a strong, unique password in production.
- Update every service that connects to the same MySQL server before changing its password.

WEBPANEL NOTES
--------------

The current WebPanel demo application does not connect directly to MySQL.
Its .env file contains Supabase configuration values, which are separate from
the MySQL password used by WebPage.py.
